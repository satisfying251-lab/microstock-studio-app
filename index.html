2. Pilih mesin analisis

AI lokal memakai model captioning yang diunduh saat pertama digunakan. Untuk OPPO F11 Pro RAM 6 GB, mulai 1–3 gambar untuk menguji kecepatan dan panas. Model lokal hanya membuat caption; 49 keyword lengkap tetap perlu AI cloud atau penyuntingan manual.
Cloud memakai Gemini 2.5 Flash-Lite API langsung dari browser. Masukkan API key sendiri. Jangan bagikan key atau gunakan di perangkat umum. Google mencantumkan free tier terbatas untuk model tertentu; kuota dan ketersediaan dapat berubah. File gambar dikirim ke Google saat dianalisis.
Mode gabungan menjalankan caption lokal dahulu, lalu mengirim gambar ke Gemini jika API key diisi. Gemini menyusun title, description, dan target 49 keyword. Jika tanpa key atau cloud gagal, aplikasi memakai caption lokal dan menandai hasil untuk review.

Key hanya disimpan di memori halaman, tidak disimpan di GitHub atau LocalStorage.

Strategi 1 · Riset sebelum produksi

Catat hasil pencarian dari marketplace yang kamu riset. Aplikasi tidak mengklaim bisa membaca jumlah hasil Adobe Stock secara otomatis.

Strategi 2 · Urutan keyword

Ketika AI menghasilkan metadata, aplikasi akan memprioritaskan 10 keyword paling penting di bagian awal. Periksa apakah sepuluh keyword tersebut benar-benar menggambarkan isi gambar.

Urutan keyword adalah prinsip yang ditampilkan dalam video, bukan jaminan ranking atau penjualan di Adobe Stock.

Strategi 3 · Kalender konten musiman

Pilih event dan tanggalnya. Aplikasi akan menghitung rekomendasi 2–3 bulan sebelum hari-H.

Strategi 4 · Pembuat variasi, bukan duplikat

Mesin AI dan privasi · OPPO F11 Pro

AI lokal: model captioning dijalankan di browser melalui Transformers.js. Model harus diunduh dari internet pada penggunaan awal. Ukuran dan kompatibilitas dapat berubah mengikuti model yang tersedia.

AI cloud: Gemini menerima gambar dan instruksi metadata. Gunakan API key pribadi dari Google AI Studio. API key tidak pernah dikirim ke server aplikasi ini, tetapi permintaan langsung dikirim dari browser ke Google.

Catatan: GitHub Pages hanya meng-host file statis. Jangan menaruh API key di kode, repository, atau file konfigurasi publik.

Batas batch dan penyimpanan

Batch maksimum 100 gambar per pemilihan. Proses berjalan satu per satu agar RAM 6 GB lebih stabil. Metadata disimpan lokal di browser melalui IndexedDB; file gambar asli tidak disimpan oleh aplikasi. Ekspor CSV secara berkala sebagai cadangan. Hapus data situs/browser dapat menghapus riwayat lokal.
